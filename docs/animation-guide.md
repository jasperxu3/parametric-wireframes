# 参数化图形动画指导

本文记录参数化线框从静态 SVG 过渡到交互式 Canvas 动画的实现方式。方案借鉴工程可视化插图与动态文字组件的表现原理，而不是复制第三方站点源码：保留静态矢量回退，在 Canvas 中重新采样几何，并叠加入场描线、参数化循环、数据 pulse、动态文字和轻量指针交互。

图集的 22 个模板均已有动态版本。`01 / 双曲颈面` 保留独立实现 [`assets/animations/catenoid-field.js`](../assets/animations/catenoid-field.js)；其余模板共享 [`assets/animations/wireframe-runtime.js`](../assets/animations/wireframe-runtime.js) 的 Canvas 生命周期，并按几何职责拆分到 `assets/animations/definitions/`：

- `spatial.js`：扭转漏斗、焦点投影锥、空间轨道核；
- `arrays-grids.js`：三个变换阵列、引力井网格、波动膜网格；
- `fields-curves.js`：分层透视网格、稀疏双极场线、干涉波束、收束编织螺旋。
- `generated-shapes.js`：透镜与超椭圆阵列、轨道编织、参数曲线、形变网格、偏斜投影和磁性场线。

[`src/components/catenoid-animation.tsx`](../src/components/catenoid-animation.tsx) 和 [`src/components/wireframe-animation.tsx`](../src/components/wireframe-animation.tsx) 负责在 TanStack Start 页面中按需加载、初始化和销毁实例。`docs/animations/` 是 `pnpm gallery` 生成的发布副本，不应直接修改。若文档、生成副本和源文件不一致，以 `assets/animations/` 下的实现为准。

所有模板共享参数化视角接口：X 轴俯仰、Y 轴水平旋转、Z 轴滚转均以角度显示，运行时转换为弧度。原生三维几何直接替换相机旋转；二维曲线先提升到 `z = 0` 平面再进行弱透视投影。外围文字不进入几何投影，因此调整角度时始终保持屏幕朝向。“正视图”对应 `[0°, 0°, 0°]`，“恢复默认视角”则重新启用每张模板原有的确定性构图、自动旋转和指针视差。

> `01` 的“左侧四行 Hyper Text + 右侧竖排 ticker”只服务于旋转曲面的负空间和参数语义，不是后续图形的通用文字模板。每个几何家族都必须重新选择文字的位置、方向和效果。

## 动画目的

这类动画属于低频浏览的展示内容，目的应是**解释几何如何生成**，而不是让装饰持续抢夺注意力。动画必须保留场景 JSON 中的公式、采样数量、颜色和基础轮廓；时间、指针和高亮只改变观察状态，不改变几何家族。

## 技术选型

- **静态 SVG**：无 JavaScript、打印、复制和加载失败时的可靠回退。
- **Canvas 2D**：逐帧绘制采样曲线、深度层级和移动纬线环。
- **手写三维数学**：欧拉旋转和弱透视投影，不引入 Three.js 或 WebGL。
- **`requestAnimationFrame`**：只处理需要实时响应时间和指针的部分。
- **`ResizeObserver`**：同步画布尺寸，并把设备像素比限制在 2。
- **`IntersectionObserver`**：图形离开视口后停止逐帧渲染。
- **Pointer Events**：仅在支持精确 Hover 的设备上启用视差。
- **`prefers-reduced-motion`**：关闭持续旋转、视差和逐帧循环，直接绘制完整静态状态。

CSS 动画适合预定的 `transform` 和 `opacity` 变化，但这个场景需要每帧重新计算曲面投影、深度排序和命中区域，因此使用 Canvas 与 `requestAnimationFrame`。

## 01 / 双曲颈面的几何

静态场景使用旋转双曲颈面：

\[
p(u,v) = [r(v)\cos u,\ hv,\ r(v)\sin u]
\]

其中：

\[
r(v) = n + (f-n)\frac{\cosh(g|v|)-1}{\cosh(g)-1}
\]

当前参数来自 `catenoid-field` 场景：

```js
const geometry = {
  neck: 0.11,
  flare: 0.94,
  growth: 1.9,
  height: 1.08
}
```

Canvas 与静态 SVG 保持相同数量：12 条纬线环、17 条固定经线；其中上下边界环固定，10 条内部环循环运动。纬线使用 120 段采样，经线使用 90 段采样。

## 三维旋转与投影

每个采样点依次应用 X、Y、Z 欧拉旋转。基础 X 轴倾角为 `0.36rad`，时间和指针只增加观察角度：

```js
const rotation = [
  0.36 + pointerPitch,
  elapsed * 0.00008 + pointerYaw,
  0
]
```

投影使用与静态渲染器一致的弱透视：

```js
const perspective = 1 + z * 0.1
screenX = centerX + x * perspective * scale
screenY = centerY + y * perspective * scale
```

它不是完整的透视摄像机，但足以根据深度产生前后尺度差，同时保持工程线框的规整感。

## 动画层次

### 1. 结构入场

路径按“从上到下的纬线 → 经线”的顺序出现。每条路径用余弦 `ease-in-out` 在 `1200ms` 内逐段绘制，相邻路径错开 `40ms`：

```js
const progress = clamp((now - start - index * 40) / 1200)
const reveal = -(Math.cos(Math.PI * progress) - 1) / 2
```

该过程解释曲面由截面环和母线构成，不使用缩放弹出或无意义的淡入。

### 2. 持续旋转

完整图形围绕纵轴缓慢旋转，速度为 `0.00008rad/ms`。运动保持匀速，因为它表达连续的空间观察，而不是一次 UI 状态切换。

### 3. 圆环收缩与展开

上下两条边界环固定在 \(v=-1\) 和 \(v=1\)，避免循环过程中两端出现空洞。其余 10 条纬线环使用均匀错开的相位，在 `5600ms` 内沿内部参数区间从 \(v=-0.9\) 移动到 \(v=0.9\)。圆环总数始终为 12；固定经线降低对比度，避免干扰运动方向。每个移动圆环从上方大半径进入，接近 \(v=0\) 时按照 `profileRadius(v)` 收缩到颈部，再向下展开到大半径：

```js
const progress = (phase + cycleElapsed / 5600) % 1
const v = -0.9 + progress * 1.8
const radius = profileRadius(v)
```

移动圆环接近内部循环边界时降低透明度但不完全消失，弱化从下方回到上方的循环接缝；两条固定边界环始终维持完整透明度。经线保持固定，作为曲面结构参照；不再绘制沿线扫描的高光或移动粒子。

### 4. 指针视差

指针位置映射为目标俯仰角和偏航角，实际角度每帧向目标插值：

```js
pitch += (targetPitch - pitch) * 0.055
yaw += (targetYaw - yaw) * 0.055
```

指针离开后目标值归零，图形自然回到自动旋转状态。该交互只在 `(hover: hover) and (pointer: fine)` 成立时启用。

### 5. 仪表式装饰层

参考工程可视化插图的层级，在几何主体周围绘制低对比度等宽标签，例如 `RING / 12`、`SAMPLE / 120` 和参数边界。左侧四行以 4.2s 为周期错峰执行 650ms 的确定性 Hyper Text 字符解码；右侧竖排说明沿裁切轨道持续重复位移，形成低速数据 ticker。底部参数保持静止，作为稳定的坐标锚点。文字不承载必须读取的信息，因此继续位于 `aria-hidden` 的 Canvas 内。

入场 900ms 后启用八路独立数据 pulse。每路使用固定 seed 生成 1.7–2.6s 周期、280–460ms 可见窗口与不同错相，因此可以自然重叠。每次出现瞬间从当前移动纬线与经线的真实交点采样屏幕坐标，以 14/16/18px 三档实心青色直角方块显示；显示期间坐标完全冻结，窗口结束后硬切消失。随机只决定交点、节奏和尺寸，不使用圆角、紫色混搭、外框、缩放、发光或尾迹。reduced-motion 模式下不绘制 pulse，文字直接显示最终内容且 ticker 停止。

这里的“多路、短暂、可重叠”是数据到达事件，而不是一次只出现一个装饰方块。方块生成后不能跟随纬线继续移动；曲面、文字和方块也不能共用一个机械循环周期，否则画面会显得同步且可预测。

## 交互控制面板

图集采用三栏工作台，而不是同时展示所有卡片：左侧图形库负责切换模板，中间区域承载当前图形的大尺寸实时画布，右侧调试面板提供小预览、公式、动画参数和导出操作。左右面板都可折叠，折叠后中间画布自动获得更多空间；移动端默认折叠为两侧把手，展开一侧时会关闭另一侧。

所有 SVG 和 Canvas 统一使用 `#0f141a` 深色背景，模板自身的背景色不进入工作台展示。线条颜色仍来自模板 `accent`，并与白色轻微混合以保证深色背景上的对比度。切换模板时，中间画布、右侧小预览、标题、公式和主题强调色同步更新。

所有图形都提供“复制 SVG”和“复制参数”；`01 / 双曲颈面` 在右侧面板增加以下设置：

- **自动旋转**：暂停或继续纵轴旋转，关闭时保留当前角度。
- **鼠标跟随**：控制指针是否改变俯仰角与偏航角，关闭后平滑回到自动观察角度。
- **旋转速度**：在 `0×–2×` 之间调整自动旋转速度。
- **圆环速度**：在 `0×–2×` 之间调整纬线环从上到下的循环速度。

控件通过 `data-animation-setting` 与 Canvas 实例绑定。旋转角和循环时间按每帧时间差累加，而不是直接用“页面运行时间 × 当前倍率”计算，因此修改速度不会造成角度或圆环位置跳变。切换到尚未实现动画的模板时，Canvas 会隐藏并暂停，工作台改为显示确定性 SVG 和静态状态说明。

## 绘制顺序

每帧执行以下步骤：

1. 清理并绘制场景背景。
2. 绘制周期性 Hyper Text 与右侧重复位移 ticker。
3. 根据当前循环相位计算每条纬线环的 \(v\) 和半径，并重新采样三维路径。
4. 计算每条路径的平均 `z` 值。
5. 从后向前排序并绘制纬线环与固定经线。
6. 绘制当前处于可见窗口的零到多个冻结数据方块。

深度只影响绘制顺序和透明度，不改变场景公式。

## 性能和生命周期

### 画布尺寸

CSS 控制展示尺寸，Canvas backing store 根据 DPR 放大：

```js
const dpr = Math.min(devicePixelRatio || 1, 2)
canvas.width = Math.round(cssWidth * dpr)
canvas.height = Math.round(cssHeight * dpr)
context.setTransform(dpr, 0, 0, dpr, 0, 0)
```

DPR 上限为 2，避免高密度屏幕把逐帧像素量放大到 9 倍或 16 倍。

Canvas 被 `hidden` 或 `display: none` 隐藏时，`getBoundingClientRect()` 会返回零尺寸。尺寸同步必须直接跳过这种状态，且不要把展示宽高写入内联样式，否则重新显示后 Canvas 可能被永久锁定为 `1px × 1px`：

```js
const bounds = canvas.getBoundingClientRect()
if (bounds.width < 2 || bounds.height < 2) return

canvas.width = Math.round(bounds.width * dpr)
canvas.height = Math.round(bounds.height * dpr)
```

### 重新播放入场

刷新按钮应在当前 Canvas 实例上调用 `restart()`，而不是为一次重播销毁并重新创建实例。该方法停止旧 RAF，重置入场时间、自动旋转、流动时间、数据 pulse 和指针状态，然后重新同步尺寸并启动渲染：

```js
restart() {
  this.stop()
  this.introStart = performance.now()
  this.autoYaw = 0
  this.cycleElapsed = 0
  this.rotation = { pitch: 0, yaw: 0, targetPitch: 0, targetYaw: 0 }
  this.resize()
  this.render(this.introStart)
  this.start()
}
```

这样参数控件和事件监听保持原实例不变，同时路径揭示会从第一帧重新开始。模板切换是另一种生命周期：切到静态模板时由 React 组件调用 `destroy(canvas)`；切回动态模板时重新 `initialize()` 并启动新实例。

### 暂停条件

满足任一条件时取消 RAF：

- Canvas 离开视口；
- 页面进入后台；
- 页面触发 `pagehide`；
- 实例被销毁。

事件通过 `AbortController` 统一清理，Observer 在 `destroy()` 中断开。

## 渐进增强与可访问性

图集始终先输出静态 SVG，再由 React 组件叠加 Canvas：

```html
<div class="preview">
  <svg><!-- 静态回退 --></svg>
  <canvas data-animation="catenoid-field" aria-hidden="true"></canvas>
</div>
```

只有 Canvas 获得 2D context、完成首次尺寸同步后，脚本才添加 `.is-animated` 并隐藏 SVG。Canvas 是装饰性替代视图，因此使用 `aria-hidden="true"`；原有标题、公式和复制操作保持可访问。

`CatenoidAnimation` 通过 `window.__parametricWireframesAnimations` 调用共享脚本的 `initialize()` 和 `destroy(canvas)`。切换到静态模板时必须销毁实例并删除 ready 状态；重新切回时创建新实例并调用 `restart()`。不要依赖脚本只在初次页面加载时扫描一次 DOM。

在 `prefers-reduced-motion: reduce` 下：

- 不启动持续 RAF；
- 不做自动旋转和指针视差；
- 不播放逐路径入场；
- 仍绘制完整几何的静态相位，保留结构信息。

## 扩展到后续图形

新增或调整模板时可以复用生命周期和绘制管线，但不能复用 `01` 的完整画面编排。每次实现前按以下顺序决策：

1. 标出主体轮廓、视觉中心和可安全放置文字的负空间。
2. 判断几何的主运动语义：旋转、径向发射、轨道、阵列、波动、流线、收束或透视纵深。
3. 区分需要持续可读的坐标锚点与只用于营造状态感的 telemetry。坐标、端点和公式默认静态。
4. 从“位置模式”和“文字效果”中分别选择有限组合；先满足几何可读性，再增加装饰。
5. 为正常动画和 reduced-motion 分别定义明确结果，然后再写绘制代码。

实现时只替换对应家族负责的部分：

1. `samplePath()`：从对应场景公式生成采样点。
2. 路径分组：决定入场顺序和拓扑含义。
3. 循环参数：选择真正有助于解释结构的参数方向，并在循环边界处理接缝。
4. 交互语义：只有指针变化能帮助观察空间结构时才添加交互。
5. 文字编排：根据模板 `id` 或几何 `family` 显式配置位置、方向、内容和效果。

不要把静态 SVG 路径解析后随意扭曲。动画应重新执行参数公式，以便任意时间点都能追溯到场景参数。

### 通用动态图的最低表现层级

除 `01` 的独立曲面编排外，其余 52 个模板也必须同时具备三层反馈，但每层都按几何家族重新设计：

1. **持续几何循环**：入场结束后，主体几何仍有可辨识且可回溯到公式的循环，例如射线传播、矩阵激活波、深度扫描、场线输运或相位推进；不能只更新画布边缘的数字。
2. **数据事件**：在真实曲线采样点、网格交点、射线或轨道点上短暂绘制实心直角方块。方块使用确定性错相，不随机漂浮、不加圆角、发光或尾迹，并在 `reduced-motion` 下完全隐藏。
3. **家族化文字反馈**：至少一个 telemetry 随循环更新，但位置和效果必须服务于当前拓扑。例如投影锥更新射线与投影进度，阵列更新矩阵索引，透视网格更新深度层，偶极场切换输运状态，螺旋更新收束阶段。

在约 `330×247px` 的移动端画布中，Canvas 文字字号不得低于 `7px`，数据方块不得小于 `7px`。移动端使用与桌面相同的运动状态，不应通过触摸设备判断关闭动画；只有 `prefers-reduced-motion` 会切换到完整静态帧。

### 文字位置必须随几何变化

文字优先占用负空间，并与几何的方向和分区建立关系；禁止把所有模板都实现成固定 Canvas 百分比上的“左侧四行 + 右侧竖排”。位置差异必须由模板 `id` 或 `family` 的确定性配置产生，不能每次加载时随机换位。

| 几何家族 | 首选文字位置 | 首选文字效果 | 应避免 |
| --- | --- | --- | --- |
| 旋转曲面 | 左右参数栏、上下边界坐标 | Hyper Text、数值更新 | 所有文字绕主体旋转 |
| 投影射线 | 消失点两侧、投影轴端点，文字保持水平 | 逐项 reveal、沿投影方向的短 ticker | 文字压住汇聚点 |
| 轨道环 | 外圈切线、四个象限或中心留白 | Spinning Text、状态轮换 | 多层文字同时绕圈 |
| 变换阵列 | 行列标题、矩阵边缘和索引角标 | Number Ticker、逐格 reveal | 复制旋转曲面的左右栏 |
| 形变网格 | 边界、波谷间留白或等高线外侧 | Typing、波次 reveal | 文字随网格持续扭曲 |
| 参数曲线 | 端点、切线或曲率采样点附近 | Typing、短 Hyper Text | 沿整条曲线密排文字 |
| 收束编织螺旋 | 入口/出口分区、纵向进程轴 | 纵向 ticker、阶段轮换 | 再增加抢眼的圆周文字 |
| 分层透视网格 | 地平线、深度层边缘或前后层标签 | 分层 reveal、受控 velocity text | 所有深度层同步移动 |
| 偶极场线 | 两个极点外侧、左右场域分区 | 极性切换、沿流向的短 reveal | 标签堵住极点和密集场线 |

表格是默认起点，不是强制版式。同一家族的不同模板如果主体偏置、留白或投影方向不同，也应调整文字锚点。若找不到不会遮挡主体的位置，宁可减少文字或完全使用静态文字。

### 文字效果按语义选择

- **Hyper Text**：适合离散采样、解码和系统状态；使用确定性字形序列，结束后恢复稳定文本。
- **Typing Animation**：适合公式、参数记录和逐步求解；通常入场播放一次，不循环删除重打。
- **Ticker / Scroll Velocity**：适合持续流、扫描、输运和明确的进度方向；只能放在有裁切边界的轨道中。
- **Number Ticker**：适合计数、层级、采样数量或参数变化；最终值必须稳定可读。
- **Word Rotate / Morph**：适合有限状态切换；状态集合和切换节奏必须固定。
- **Spinning Text**：只用于几何本身具有明确轨道或环形语义的画面，而且旋转层级不能压过主体。
- **Text Reveal**：适合透视层、遮罩扫描或分层展开；揭示方向应与几何生成方向一致。
- **静态文字**：始终是合法选择。坐标锚点、边界值和关键公式通常不应持续运动。

每个模板最多使用 **一个持续型文字效果** 和 **一个短暂或事件型文字效果**，其余文字保持静态。禁止把 Hyper Text、Scroll Velocity、Spinning Text 和 Typing 全部叠在同一画面，也禁止让文字效果、主体循环和数据 pulse 全部同频。

### 差异化实现约束

- 必须通过模板 `id` 或几何 `family` 选择文字布局和效果；不要在共享 renderer 中随机散布标签。
- 相同 scene、seed、画布尺寸和时间状态必须得到相同文字内容与位置。
- 动态文字只能承载装饰性 telemetry；用户必须读取的信息留在可访问 DOM，不能只画进 `aria-hidden` Canvas。
- 文字不得遮挡主体轮廓、关键交点、投影消失点或高密度场线，也不得制造按钮、标签页等虚假操作暗示。
- reduced-motion 下移除 scramble、typing、ticker、morph 和 spinning，首帧直接显示最终静态文案。
- 持续运动层应有明确主次：通常保留一个几何主运动；文字持续运动只是低对比度辅助层。

## 验证清单

- 静止帧仍能识别为原始几何家族。
- 动画不修改场景 JSON 或静态 SVG 输出。
- Canvas 不可用时 SVG 正常显示。
- 离屏和后台状态没有活跃 RAF。
- 1× 与 2× DPR 下线条清晰且尺寸一致。
- 鼠标、触摸和 reduced-motion 三种环境均可用。
- 从动态图形切换到静态图形再切回时，Canvas 恢复正确尺寸。
- 刷新按钮会重置时间状态并从入场动画开始重播。
- 重新运行 `pnpm gallery` 后动画资源仍被复制到 `docs/animations/`。
- 文字位置与当前几何的负空间、方向和拓扑相符，没有直接复制 `01` 的布局。
- 一个模板不超过一个持续型和一个事件型文字效果，坐标与关键公式保持稳定可读。
- 相同输入可复现相同文字编排；reduced-motion 首帧显示完整静态文案。
